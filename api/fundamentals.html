Fundamental solutions

All kernels live in src/Fundamental_Solutions.jl, ported from the legacy calsolfund / caldsolfund / calsolfund_hiper routines and rewritten with StaticArrays + Tensorial.jl.

Quick reference

PhysicsTypeMain APINotes
LaplaceLaplacefundamental, fundamental_hyper$q=-k∂T/∂n$
HelmholtzHelmholtzfundamental, fundamental_hyperHankel $H_n^{(1)}$
Isotropic elasticityElasticityfundamental, fundamental_stress, fundamental_gradKelvin; Mat{dim,dim}
Anisotropic elasticityAnisotropicElasticityfundamental, fundamental_stress, lekhnitskii_paramsLekhnitskii

Return types:

KernelPair(U, T)       # U → G (Neumann/traction), T → H (Dirichlet/displacement)
StressKernels(D, S)    # 3rd-order tensors for interior stress

Iterable: G, H = fundamental(...) still works via KernelPair iteration when you use the props-based API; the BEMdata methods keep the legacy (U, T) / (G, H) tuple return for assembly.

Laplace

lap = Laplace(1.0)
r, n = Point2D(0.3, 0.4), Point2D(1, 0)
kp = fundamental(lap, r, n)          # KernelPair
G, H = kp.U, kp.T

# hypersingular (HTBIE)
kh = fundamental_hyper(lap, r, n, Point2D(0, 1))

2D:

\[G=-\frac{\log R}{2\pi k},\qquad H=\frac{\mathbf r\cdot\mathbf n}{2\pi R^2}.\]

3D:

\[G=\frac{1}{4\pi k R},\qquad H=\frac{\mathbf r\cdot\mathbf n}{4\pi R^3}.\]

Helmholtz

helm = Helmholtz(; ω=2π, c=340.0)
κ = wavenumber(helm)                 # ω/c
kp = fundamental(helm, r, n)         # complex KernelPair

\[G=\frac{i}{4}H_0^{(1)}(κR),\qquad H=-κ\frac{i}{4}H_1^{(1)}(κR)\,\frac{\mathbf r\cdot\mathbf n}{R}.\]

Isotropic elasticity (Kelvin)

Uses Tensorial Mat{2,2} / Mat{3,3} for the displacement and traction kernels, and Tensor{Tuple{2,2,2}} for stress kernels.

el = Elasticity(210e9, 0.3, 7800.0; plane_strain=true)
kp = fundamental(el, r, n)
U, T = kp.U, kp.T                    # Mat{2,2}

# interior stress recovery kernels
sk = fundamental_stress(el, r, n)    # D, S  (3rd-order)
# σ_ij = D_kij t_k - S_kij u_k

# Cartesian derivatives of U, T
Ux, Tx, Uy, Ty = fundamental_grad(el, r, n)

Plane stress is obtained by the standard mapping $ν̃ = ν/(1+ν)$ (plane_strain=false).

Helpers: shear_modulus, lame_λ, effective_nu.

Anisotropic elasticity (Lekhnitskii)

# orthotropic engineering constants → complex parameters
pars = lekhnitskii_params(E1, E2, G12, ν12; θ_deg=30)
mat  = AnisotropicElasticity(pars)

# field y, source x, normal at y
kp = fundamental(mat, y, x, n)
sk = fundamental_stress(mat, y, x, n)

Built from the compliance characteristic equation (legacy Compute_Material).

BEMdata integration

Assembly still calls:

Gij, Hij = fundamental(dad, r, n)   # numbers or SMatrix

which dispatches on dad.properties.
